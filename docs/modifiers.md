# Modifiers

A modifier is a function that writes methods for a type at compile time. `Display`, `Debug`, `JsonCodec` and `Args` are modifiers, and a package can define its own. This chapter writes one: a `Same` trait that compares two values field by field. [std.meta](std/meta.md) is the reference for the types a modifier uses.

## How a type asks

| Step | What happens |
|---|---|
| a trait names its modifier | `@generate(same_modifier)` on the trait |
| a type lists the trait | `struct Point: (Same)` |
| the type writes none of the trait's methods | the compiler runs the modifier on a description of the type |
| the modifier answers source text | the methods are added to the type, before the program is checked |
| the type writes a method itself | the modifier does not run, so a method you write always wins |

## The trait and its modifier

They live in one module of a package. The modifier is a `pub fn` marked `@modifier`, from a `Decl` to `Result<Additions, Diagnostic>`.

```mote,skip
import std.meta as meta
import std.string as str

@generate(same_modifier)
pub trait Same {
    fn same(self, other: Self) -> Bool
}

@modifier
pub fn same_modifier(d: meta.Decl) -> Result<meta.Additions, meta.Diagnostic> {
    match d.kind {
        meta.DeclKind.Enum => { return Err(meta.Diagnostic.new("`" + d.name + "` is an enum, and `Same` compares the fields of a struct or class")) }
        _ => {}
    }
    var tests: List<String> = []
    for f in d.fields {
        tests.push("self." + f.name + " == other." + f.name)
    }
    var body = "true"
    if tests.len() > 0 {
        body = str.join(tests, " && ")
    }
    return Ok(meta.Additions.new("fn same(self, other: Self) -> Bool { return " + body + " }"))
}
```

The answer is plain text. The compiler parses it and adds each `fn` to the type, so a mistake in it is reported like any other error.

## Using it

Another module or package imports the trait and lists it.

```mote,skip
import { Same } from same

struct Point: (Same) {
    x: Int
    y: Int
}

println(Point { x: 1, y: 2 }.same(Point { x: 1, y: 2 }))
```

```output
true
```

`mote expand` prints the module with the methods written inside the type, under a `// generated by Same (requested at line 3)` comment.

## Testing it

A modifier is an ordinary function, so a test builds a `Decl` and compares the text it answers.

```mote,skip
import std.meta as meta
import ..src.lib as same

test "every field is compared" {
    let int = meta.TypeRef.new(meta.TypeKind.Named, "Int")
    let decl = meta.Decl.new(meta.DeclKind.Struct, "P", fields = [meta.Field.new("x", int), meta.Field.new("y", int)])
    let out = same.same_modifier(decl).unwrap()
    assert_eq(out.public, "fn same(self, other: Self) -> Bool { return self.x == other.x && self.y == other.y }")
}
```

## Rules

| Rule | Effect |
|---|---|
| a modifier reads one declaration | it sees fields, variants, listed traits, generics, attributes and the names and signatures of methods the type already has; it sees no other declaration and no method body |
| types are read as written | `List<Int>` is a `Generic` named `List`; aliases are not followed |
| a modifier only adds methods | it cannot change a field, a trait list or an import |
| a name that clashes with a method is an error | the error names both |
| the answer comes back as `public` and `private` text | `public` methods can be called from other modules; `private` helpers are named `__…` |
| `Err(Diagnostic)` refuses the type | the message is reported where the trait is listed, as ``listing `Same`: …`` |
| the module holding a modifier imports only `std.meta`, `std.string`, `std.iter`, `std.collections` and `std.math` | it has no files, network or clock |
| that module cannot list a trait with a modifier or define `main` | a modifier cannot depend on its own output |
| a run ends after 20 million steps, 64 MiB or 1 MiB of output | the error says the modifier did not finish |
| the same declaration gives the same answer | so answers are kept in the build cache |

## Attributes on fields

`@arg` is the one attribute a type or an enum variant can carry for a modifier, and an attribute no modifier reads is an error. A field carries no attribute: a modifier reads its `doc` (the `///` lines before it) and its `default` instead. A modifier says which it reads with `@modifier(reads = "arg")`; several names go in one string. [Command-line arguments](std/args.md) is the example.

## What stays fixed

The types in `std.meta` and the four modifiers in `std.derive` are `@stable`: a change to them fails the build, so a package's modifier keeps working across releases.
